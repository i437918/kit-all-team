## Идентичность выпуска

- объект защищённого аннотированного тега `v0.1.0`: `4f838e0c701dbd16a006652e74b75cbfa9355370`;
- коммит, на который разворачивается тег: `8f06652c1d3ff97701e0e19b52f22967a7321d9e`;
- сообщение тега: `1C Team Kit v0.1.0`.

Защищённый аннотированный тег — сильная идентичность выпуска: он связывает имя `v0.1.0` с точным коммитом. Коммит документации создан после защищённого тега и не изменяет выпущенные файлы, их байты или сам тег.

GitLab Release и метаданные сохранённого задания могут изменяться. Поэтому их нельзя называть неизменяемыми. В частности, сохранение задания без срока удаления не делает содержимое криптографически неизменяемым; проверяйте SHA-256 из таблицы ниже и соответствие защищённому тегу.

## Принятые ограничения

- trusted corporate-network evidence недоступно для точного коммита выпуска: GitHub-hosted runner не разрешает внутренний DNS `gitlab.tools.enterprise.ru`, а подходящий self-hosted runner внутри корпоративной сети/VPN не использовался.
- Для ALT Linux проверен только pinned p11 userspace; нативная ALT Linux и QEMU/VM не проверены.
- Бинарники Team Kit не подписаны. Сборки macOS также не подписаны Apple и не notarized.
- Установка Hermes в Windows выполняется вручную через графический мастер. Проверки SHA-256 и Authenticode не являются доказательством unattended-установки, её завершения или выбранного каталога.
- Офисные документы не поддерживаются.

Эти ограничения приняты для внутреннего `v0.1.0`; выпуск нельзя описывать как публичный, подписанный или полностью проверенный на всех корпоративных платформах.
