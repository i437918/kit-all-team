# Дизайн русскоязычного нумерованного мастера

## Цель

Сделать интерактивный мастер Team Kit понятным пользователю без знания внутренних идентификаторов: все вопросы и пояснения выводятся на русском языке, а каждый закрытый вариант выбирается вводом номера.

## Границы поведения

Состав поддерживаемых значений не меняется. В частности, AI-приложения показываются одним списком из 11 пунктов: Hermes, Cursor, Claude Code, Codex, OpenCode, Kilo Code, Kimi, Qwen, Command Code, Cline и Pi. Отменённая группировка «Hermes / Другое AI-приложение» не реализуется.

Нумерованные меню применяются к:

- операционной системе;
- AI-приложению;
- наличию установленного приложения;
- проекту;
- роли;
- одному набору skills;
- варианту обновления непустого окружения.

Пути `KIT_ALL_TEAM_HOME` и `HERMES_HOME` вводятся текстом, потому что это значения пользователя, а не закрытые варианты. Логин и секреты также вводятся текстом; секретные значения остаются маскированными.

## Вид интерфейса

Каждое меню выводит вопрос, затем по одному пункту на строку и приглашение `Введите номер ответа:`. Например:

```text
Выберите AI-приложение:
  1. Hermes
  2. Cursor
  3. Claude Code
  4. Codex
  5. OpenCode
  6. Kilo Code
  7. Kimi
  8. Qwen
  9. Command Code
  10. Cline
  11. Pi
Введите номер ответа:
```

Внутри `DesiredState` и `.env` сохраняется существующий стабильный ID выбранного пункта, например `codex`, а не число или отображаемое русское название.

## Обработка ввода

- Допустим только номер существующего пункта после удаления пробелов.
- Пустая строка, текст, `0` и номер вне диапазона выводят `Некорректный номер. Введите число от 1 до N.` и повторяют то же меню.
- Отмена контекста немедленно прекращает ожидание.
- Конец входного потока без допустимого ответа завершается стабильной ошибкой `INPUT_REQUIRED`, а не бесконечным циклом.
- Ответы `yes`, `windows`, `developer` и другие прежние текстовые варианты в интерактивном режиме больше не принимаются.

## Совместимость

Неинтерактивный CLI сохраняет существующие флаги и значения: `--os windows`, `--app hermes`, `--role developer` и остальные. Существующие `.env`, квитанции, каталоги, проверки `PATH`, расположение приватных секретов и handoff для альтернативных приложений не меняются.

## Русские формулировки

Мастер использует формулировки `Выберите операционную систему`, `Выберите AI-приложение`, `AI-приложение уже установлено?`, `Введите KIT_ALL_TEAM_HOME`, `Введите HERMES_HOME`, `Выберите проект`, `Выберите роль`, `Выберите набор skills` и `Что обновить в существующем окружении?`.

Подсказки секретов становятся понятными русскими фразами с сохранением имени переменной в скобках: логин GitLab, токен GitLab и ключ CustomLLM. Значения не отображаются.

## Документация и выпуск

README обновляется в соответствии с фактическим русским меню и нумерацией. Текущий опубликованный `v0.1.0-rc.1` не заменяется: новые бинарники должны получить следующий номер кандидата в релиз после завершения реализации и всех проверок.

## Проверка

- TDD-тесты фиксируют точный русский вывод, соответствие номеров внутренним ID, повтор после неверного ввода, EOF и отмену.
- Регрессионные тесты подтверждают неизменность неинтерактивных флагов.
- Полный `go test ./...`, `go vet ./...` и кросс-сборки Windows/Linux/macOS должны пройти до выпуска нового RC.
