# Дизайн GitLab-asset с корпоративными сертификатами

## Цель

Сделать закреплённый `certs.zip` доступным пользователю непосредственно в GitLab-релизе `v0.1.0-rc.1`, чтобы архив не требовалось отдельно получать у администратора.

## Выбранный вариант

Архив загружается в закрытый GitLab-проект как Project Upload и добавляется в список assets релиза ссылкой с именем `certs.zip`. Сам ZIP и PEM-файлы не добавляются в Git-историю. README получает прямую ссылку на release asset, инструкцию скачать его вместе с бинарником и точный SHA-256.

Этот вариант быстрее размещения в Package Registry и не требует изменения бинарников. Он также сохраняет действующий запрет на отслеживаемые сертификаты и архивы в репозитории.

## Проверки перед публикацией

- Исходный файл: `G:\Почтатех\AI\certs.zip`.
- Размер: `136410` байт.
- SHA-256: `88d85e7e7d64c061c195f93c517500bdc91fccfb9b5a8115da9f6a5a17e689f8`.
- SHA-256 совпадает с `bootstrap.DefaultCertificateSHA256`.
- Архив содержит только `certs/ca-bundle.pem`, `certs/enterprise-ca-chain.pem` и `certs/enterprise-issuing-ca.pem`.
- Имена файлов и содержимое проверяются на маркеры приватных ключей до загрузки.

## Публикация и документация

GitLab API используется без вывода токена в журнал. Сначала создаётся upload, затем к релизу добавляется ссылка типа `other`. После изменения повторно читается релиз и проверяется, что asset с точным именем и возвращённым GitLab URL присутствует.

В `README.md` формулировка «выданный администратором» заменяется указанием скачать `certs.zip` со страницы того же релиза. Рядом публикуется SHA-256, а инструкции для Windows, macOS, Linux и ALT Linux требуют положить архив рядом с бинарником перед запуском Hermes.

## Границы

- Уже опубликованные бинарники не изменяются.
- Сертификаты не встраиваются в executable.
- Архив доступен только пользователям, имеющим доступ к закрытому GitLab-проекту.
- Автоматизация включения архива во все будущие релизы в эту задачу не входит.

## Проверка результата

- API релиза возвращает asset `certs.zip`.
- Загруженный из GitLab файл имеет исходный SHA-256.
- `README.md` не предлагает запрашивать архив у администратора.
- `git diff --check` и `go test ./test/release -count=1` проходят.
