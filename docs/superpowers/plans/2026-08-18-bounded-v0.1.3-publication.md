# Bounded v0.1.3 Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подготовить TeamKit `v0.1.3` с обязательными Jira и Confluence MCP и фактически опубликовать полный GitLab Release одним неинтерактивным запуском не дольше 180 минут.

**Architecture:** Текущая ветка от `v0.1.2` получает минимальный Atlassian-port и замораживает один release SHA. Узкий PowerShell-оркестратор проверяет все права до mutation, параллельно ожидает exact-SHA GitHub/GitLab CI, сравнивает артефакты и только затем создаёт protected annotated tag и GitLab Release с forward-only recovery.

**Tech Stack:** Go 1.26.6, PowerShell 7, GitHub REST/Actions, GitLab API v4 project `12087`, Git, Hermes Agent 0.20.x.

## Global Constraints

- База функционального переноса: tag `v0.1.2`, commit `03b823588dd27e3bd0c0236f417eabbc2aef6ac4`.
- Активная версия: только `v0.1.3`; release URL: `https://gitlab.example.invalid/1c/aisuz/ai/-/releases/v0.1.3`.
- Jira и Confluence MCP для Hermes всегда имеют `enabled: true`.
- Jira URL/header: `https://llm.example.invalid/jira/mcp`, `x-mcp-jira-authorization: Token ${HERMES_CUSTOM_ISSUE_TRACKER_TOKEN}`.
- Confluence URL/header: `https://llm.example.invalid/confluence/mcp`, `x-mcp-confluence-authorization: Token ${HERMES_CUSTOM_KNOWLEDGE_BASE_TOKEN}`.
- Оба MCP используют `x-litellm-api-key: Bearer ${HERMES_CUSTOM_LLM_API_KEY}`.
- Значения трёх секретов не попадают в argv, URL, YAML-литералы, Git, plan, receipt, operation, stdout, stderr, execution log или release report.
- Скрипт не содержит `Read-Host`, confirmation prompts, force push, reset, delete tag или delete Release.
- `MaxMinutes` не превышает 180; deadline exit code — `124`; tag запрещён при остатке менее 20 минут.
- GitHub `main` и GitLab `master` получают один SHA обычными fast-forward pushes.
- Публикационный набор: четыре `teamkit-v0.1.3-*`, `SHA256SUMS`, `SECURITY-AUDIT.json`, `Hermes-Setup.exe`, `certs.zip`.
- Успех задачи — только фактический итоговый JSON `status:"published"`; dry-run, PR, candidate и tag без Release не являются завершением.
- После заморозки release SHA исходники не изменяются до публикации; evidence сохраняется как игнорируемый JSON/CI artifact, не новым release commit.
